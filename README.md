# Dormitory Management System

A web-based dormitory automation project designed to organize student accommodation and administrative operations.

## Overview

The application brings together student, room, staff and financial records in a single management system. Its codebase follows the ASP.NET MVC architecture and separates application responsibilities into controllers, models and views.

## Technology Stack

- C#
- ASP.NET MVC 5
- Entity Framework
- Microsoft SQL Server
- ASP.NET Identity
- HTML, CSS, JavaScript and Bootstrap

## Main Areas

- Student record management
- Room and department management
- Room occupancy tracking
- Staff management
- Expense and debt records
- Administrative access and user authentication

## Getting Started

1. Clone this repository.
2. Open `projeSerB/projeSerB.sln` in Visual Studio.
3. Restore the NuGet packages.
4. Configure the database connection in the application's `Web.config`.
5. Prepare the SQL Server database and apply the required schema.
6. Run the web project using IIS Express.

> The application requires a compatible SQL Server database. Connection strings and credentials must be configured locally; do not commit private credentials.

## Notes

The repository includes the Visual Studio solution and application source. A public live demo is not currently provided.
